# Mascot concept assets

Generated with the built-in GPT image generation tool on 2026-11-02 for dGrape. These are original sloth concepts using the general approachability of the approved design references, not copies of their characters.

- sloth-concept.png: first detailed exploration, retained as iteration history. The user requested a simpler character afterward.
- sloth-simple-concept.png: active simplified direction, with welcome, organizing, and report poses. This is a concept sheet with a light background, not final transparent production artwork.
- public/brand/sloth-concept.png at the repository root: runtime copy of the simplified sheet for the design-system sample.

The simplification brief removes fur detail, realistic rendering, pouch/jewelry, and complicated props in favor of rounded shapes, a clear sloth mask, minimal outlines, and purple data props. Final artwork and individual transparent pose assets remain open to user curation.

Do not return to the detailed concept as the default style. Regenerate or edit through image generation when visual changes are requested; preserve the active source and runtime copy together.
