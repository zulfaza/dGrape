Schema changes without deployment

Rename a label while preserving its field ID. Publish a new version for added fields. Type changes require validation and migration. The example field syntax is proposed, not implemented.

Proposed speed targets

API p95 under 1 second for supported indexed pages and summary reports. Useful dashboard within 2 seconds.

Capacity validation

Test at least 500,000 primary records, concurrent use, and a 1,000-record batch import. Measure cost and index overhead.

Targets are unmeasured. Summary freshness target: within 60 seconds of committed changes. Unusual heavy reports run as background jobs with visible progress.
