# Product

## Register

product

## Users

People using agent harnesses to organize data, connect APIs, schedule deterministic work, store artifacts, and create useful dashboards. Job applications and transactions are initial examples.

## Product Purpose

Provisional name: DFE, Dashboard for Everything. Intended production domain: dfe.makarima.dev. The repository retains its existing directory name.

DFE is a general data workspace built for agents. Users keep their existing harness; MCP supplies persistent data and capabilities, while the dashboard makes results, freshness, and failures easy to inspect.

## Brand Personality

Friendly, capable, clear. A calm sloth mascot gives the product character while operational screens remain precise.

## Anti-references

Avoid generic SaaS-card layouts, excessive decoration inside data views, pressure-based gamification, and an austere theme that hides the product's approachable character.

## Design Principles

- Use shadcn/ui controls with a deliberate, accessible theme.
- Highlight flexible data, API connections, schedules, artifacts, and dynamic dashboards through concrete examples.
- Keep data views readable and fast; concentrate illustration in onboarding and feature explanations.
- Use an original sloth mascot inspired by the approachability of Oyenza and GitHub.
- Make freshness, job progress, permissions, and recovery actions explicit.
- Keep reusable data and agent workflows independent of a particular domain.

## Accessibility & Inclusion

Use semantic controls, keyboard-friendly interactions, visible focus states, and reduced-motion-safe UI.
